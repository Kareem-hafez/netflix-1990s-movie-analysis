# 🎬 Netflix 1990s Movie Analysis

Exploratory data analysis of Netflix movies released during the **1990s**, using Python, Pandas, and Matplotlib.

## 📊 Project Questions

* What was the most frequent movie duration in the 1990s?
* How many short action movies were released in the 1990s?

A short movie is defined as having a duration of **less than 90 minutes**.

## 🛠️ Tools

* Python
* Pandas
* Matplotlib
* Exploratory Data Analysis

## 🔍 Analysis

The dataset was filtered to include movies released between **1990 and 1999**. A histogram was then used to visualize the distribution of movie durations.
